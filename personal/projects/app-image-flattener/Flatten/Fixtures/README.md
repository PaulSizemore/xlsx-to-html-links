# Test fixtures

- `lrcat/` — Lightroom Classic catalog backups imported via
  `scripts/import-fixtures.sh`. The `.lrcat` files are personal data and are
  **gitignored**; only `manifest.tsv` (filename, `Adobe_DBVersion`, size,
  import date) is committed, so CI and Phase 1 tests can assert which schema
  versions the corpus covers.
- Synthetic edge-case catalogs (renamed volumes, moved folders, RAW+JPEG,
  ambiguous relinks) are generated by Phase 1 tooling and will live alongside.

To (re)populate on a machine with access to the backups:

```sh
scripts/import-fixtures.sh /path/to/backups/*.lrcat
```
